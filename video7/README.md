# Vídeo 7 — "Por que o 13º some mais rápido que o salário?"

Vídeo vertical 1080x1920, 30fps, 82,5s com narração (voz Drew, `public/narracao.mp3`), cenas e legendas sincronizadas com a fala, Remotion. Trilha e efeitos 100% sintetizados (100 BPM, Lá menor, guizos de Natal até a resposta, piano depois).

Dados: DIEESE (nov/2026) — 13º deve injetar R$ 399,1 bi; média R$ 3.720; 1ª parcela até 30/11.
Exemplo: gastos 900 + 600 + 450 + 1.200 + 570 = 3.720. Divisão 50/30/20: 1.860 + 1.116 + 744 = 3.720.
Psicologia: efeito "dinheiro da casa" (house money effect, Thaler) e experimento "bônus" vs. "devolução" (bônus gastou mais).
